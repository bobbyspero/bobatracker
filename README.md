# 🧋 Boba Quest - Bay Area Tracker

A Game Boy-styled boba drink tracker for the Bay Area with interactive maps and shop ratings!

## Features

- 🎮 **Retro Game Boy aesthetic** with authentic green/black color scheme
- 🗺️ **Interactive map** showing real Bay Area boba shops
- 😊 **Happiness meter** that tracks your boba consumption
- ⭐ **Top-rated shops** with real ratings and locations
- 📱 **Fully responsive** design for mobile and desktop
- 🎯 **Shop tracking** to remember where you've been

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Tech Stack

- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Leaflet** - Interactive maps
- **Doto Font** - Retro typography

## How to Use

1. **Log Drinks** - Click "LOG DRINK" on any shop to record your boba consumption
2. **Check the Map** - Click boba markers to see shop details and log drinks directly from the map
3. **Track Happiness** - Your happiness increases with each drink and decays over time
4. **Collect Shops** - Visit different shops to collect them all (marked with 🧋)

## Game Boy Color Scheme
